# foundation: scaffold ARMA API Hub control plane

Phase 0 foundation for the ARMA API Hub control plane. This PR scaffolds the
monorepo, shared contracts, runtime packages, apps, tests, and required
documents, and adds the API Cost and Usage Guard. It does not connect to any
production system, does not connect real vendor accounts, does not import
production invoices, does not activate production billing, and does not send
live cost events to the FSTS AI Hub or to REGIVANTA.

## Architecture decisions

- **Runtime:** Node.js 24, TypeScript strict, pnpm workspaces, Turborepo.
- **Topology:** console, service-facing API, and durable worker deploy
  independently. Webhook delivery and durable jobs run in the worker, never in
  short-lived frontend functions.
- **Security:** HMAC-SHA256 canonical request signing with timing-safe compare,
  clock-skew and nonce replay windows; fail-closed policy engine; lifecycle
  gating; capability scoping; classification ordering; tenant-scope enforcement.
- **Delivery:** fail-closed by default (`API_HUB_OUTBOUND_DELIVERY_DISABLED=true`);
  durable retry with backoff, dead-letter, and failure classes.
- **Boundary:** each product owns its DB, business logic, authz, and customer
  data; no cross-product DB access; no browser/mobile client holds privileged
  API HUB credentials.

## Cost and Usage Guard

The API Cost and Usage Guard is added under `convex/` and `packages/contracts`.
It measures and governs the cost of external APIs, connectors, webhooks,
retries, data transfer, and API-related storage, and it is the authoritative
source for the charge a vendor levies for an external request.

- **Cost-ownership boundary (locked):** the API Hub owns external API/connector/
  webhook/retry/data-transfer/API-storage cost; the FSTS AI Hub owns AI model/
  provider/token/prompt/agent/retrieval/AI-execution cost; REGIVANTA Cost Guard
  owns profitability, margin, allocation, budgets, forecasts, and executive
  reporting. The API Hub does not compute profitability or margin and does not
  select AI models or inspect prompts. The AI Hub does not recreate API billing,
  connector quota, webhook-cost, retry-cost, or vendor-price logic. REGIVANTA
  does not re-measure vendor usage.
- **Schema:** 16 cost tables (`apiVendors`, `vendorPriceVersions`,
  `connectorSubscriptions`, `apiUsageRecords`, `apiCostEvents`,
  `rateLimitWindows`, `quotaAllocations`, `usageBudgets`, `spendingLimits`,
  `costAnomalies`, `optimizationDecisions`, `cacheUsageRecords`,
  `batchUsageRecords`, `retryWasteRecords`, `vendorShutdownControls`,
  `costExportReceipts`) with indexes for vendor+effective date,
  connector/system/tenant/customer+billing period, correlation, causation,
  idempotency, cost-event, request, pricing-version, budget status, anomaly
  status, and shutdown status. No unbounded `.collect()`.
- **Exact money:** integer minor currency units only; the deterministic cost
  primitives reject non-integer/unsafe-integer input. Every amount records
  currency, quantity, unit type, unit price, pricing source, vendor price
  version, effective date, calculation version, and estimated/finalized status.
  Vendor price versions are immutable; historical usage is never overwritten.
- **Deduplication:** the cost ledger deduplicates on both the cost-event
  identifier and the idempotency key, so the same external charge is never
  counted twice.
- **Controls:** rate-limit windows, quota allocations, usage budgets, spending
  limits (warn/throttle/block), anomaly detection, optimization decisions,
  cache/batch/retry-waste records, and emergency vendor shutdown. Every warning,
  throttle, block, approval, and shutdown writes an audit event.
- **Normalized cost events (11):** `apiHub.apiUsageRecorded`,
  `apiHub.apiCostRecorded`, `apiHub.retryWasteRecorded`,
  `apiHub.cacheSavingsRecorded`, `apiHub.batchSavingsRecorded`,
  `apiHub.quotaThresholdReached`, `apiHub.budgetThresholdReached`,
  `apiHub.costAnomalyDetected`, `apiHub.connectorSpendBlocked`,
  `apiHub.vendorShutdownActivated`, `apiHub.costExported`. Each carries the
  authoritative source hub, event/schema version, vendor, connector, FSTS
  system, tenant/customer scope where authorized, correlation/causation IDs,
  idempotency key, usage quantity/unit, exact amount/currency, vendor price
  version, estimated/finalized status, timestamp, and audit reference.
- **Handoff contracts:** the AI Hub handoff contract references an authoritative
  API Hub cost event and carries no monetary field and no AI content; the
  REGIVANTA export contract carries measured usage and cost and no profitability
  field.
- **Phase 0 limit:** no real vendor accounts, no production invoices, no
  production billing, no live cost events to the AI Hub or REGIVANTA. Sanitized
  fixtures only; no production vendors.
