# Contributing

ARMA API Hub is proprietary FSTS software. Public visibility is not an invitation to use the code or an unrestricted open-source contribution program.

## Before contributing

- Open or reference an approved issue.
- Do not include secrets, customer data, production identifiers, or third-party confidential material.
- Keep each pull request limited to one approved concern.
- Add or update tests, contracts, threat analysis, and documentation as applicable.
- Do not create a production connector without an approved architecture decision record.
